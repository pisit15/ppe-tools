# Label font

NotoSansThai.ttf is the unchanged Noto Sans Thai variable font from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/notosansthai

Source filename: NotoSansThai[wdth,wght].ttf, downloaded 2026-10-09.
License: SIL Open Font License 1.1, included in NotoSansThai-OFL.txt.
Hosted locally so label generation does not depend on a third-party font request.
